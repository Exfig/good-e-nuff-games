Privacy policy: Good-E-Nuff Games uploader

Last updated: 26 October 2026

What the app is

The Good-E-Nuff Games uploader is a private desktop tool used only by the owner of the Good-E-Nuff Games YouTube channel to upload that channel's own videos. It uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of your data is covered by the Google Privacy Policy.

What data it accesses

  • Through Google sign-in (OAuth), permission to upload videos to the signed-in channel and to manage that channel's videos (scopes youtube.upload and youtube).
  • The signed-in channel's name and id, to confirm the right channel is signed in.
  • The status of videos it has uploaded (privacy, upload and processing state).

It does not read comments, subscribers, viewers' data, or any other channel's data.

How the data is used and stored

  • The sign-in tokens are stored only in a file on the channel owner's own PC, and are used only to make the uploads described above.
  • Video ids returned by YouTube are saved in the episode's local project files so the owner can find each upload.
  • Nothing is sent to any server other than Google's. No data is sold, shared with third parties, used for advertising, or used to train AI models.

Cookies

The app is a desktop tool and sets no cookies. This website sets none either.

Revoking access and deleting data

Access can be revoked at any time from the Google account's third-party connections page (Google security settings). Deleting the local token file removes the stored sign-in; no copy exists anywhere else. Stored data is deleted within 7 days of access being revoked.

Contact

Questions about this policy: open an issue at github.com/Exfig/good-e-nuff-games.
